## Verdict in one line

shippable today.** Phase 0 of the existing roadmap (~1 sprint) is the gap between "works on
Sid's machine" and "can sit on a public URL without embarrassment."

## What it is

Multi-agent travel planner: natural-language query → planner agent → SerpAPI flights +
OpenWeather → LLM explanation (Ollama → Gemini → OpenAI fallback routing with circuit
breakers + key rotation) → SSE streaming to a React 19/Vite frontend → booking handoff via
provider checkout URLs. **No payments — booking is a handoff, by design.**
FastAPI + SQLAlchemy/Postgres + Docker Compose (+ Prometheus/Grafana profile), local RAG.
