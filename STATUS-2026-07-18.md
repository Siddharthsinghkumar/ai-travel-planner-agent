## What it is

Multi-agent travel planner: natural-language query → planner agent → SerpAPI flights +
OpenWeather → LLM explanation (Ollama → Gemini → OpenAI fallback routing with circuit
breakers + key rotation) → SSE streaming to a React 19/Vite frontend → booking handoff via
provider checkout URLs. **No payments — booking is a handoff, by design.**
FastAPI + SQLAlchemy/Postgres + Docker Compose (+ Prometheus/Grafana profile), local RAG.

## M1 Complete — 2026-07-18

M1 ("Truth & Hardening") executed in 3 batches over 1 day, delivering all Phase-0 fixes plus
CI/API hardening. 24 tasks committed, no regressions, no weakened tests.

**Outcomes:**
- **Event-loop unblocking:** `/health` P95 = 4.4ms under induced DB pressure (pg_sleep(45)).
  All DB writes in key-manager, price-tracker, and provider-override surfaces run off the event
  loop via `asyncio.to_thread`.
- **Auth hardened:** `AUTH_DISABLE` honors only `TESTING=1` (red banner otherwise); admin
  bypass split to `AUTH_DISABLE_ADMIN`; HITL approvals bound to plan owner principal (403
  on mismatch).
- **Prometheus alive:** scrapable on internal port 9091.
- **KPI telemetry restored:** `log_event()` moved out of swallowed `IllegalTransition` blocks.
- **Dead code purged:** 2 dead modules + 3 repo-root artifacts + `local.db` + `__main__` block.
- **Dependency truth:** 5 unused packages removed, pydantic pinned, RAG disabled loudly,
  lockfiles added, venv rebuilt from truthful manifest.
- **Queue safety:** ephemeral contract enforced, per-job timeout, `await put()` on rehydrate.
- **Session hygiene:** expiration cleanup on price-tracker cadence, per-session message cap.
- **DB fail-fast:** no silent SQLite fallback outside tests.
- **CI real:** ruff, fast suite (210), slow suite+Postgres (252/6xfail), import check,
  semgrep async-DB guard, ZAP baseline, pip-audit, npm-audit — all in parallel.
- **API hardened:** `extra="forbid"` on all request models; handoff URL injection blocked
  at model layer; rate-limiter fails closed on sensitive paths.
- **Tests**: 210 fast green, 252 slow green (6 visible xfails — pre-M1 drift, pending
  Sid review). Ruff 0 under committed config.

**Unfinished by design:** planner_agent decomposition (WS-A, post-ship), frontend rebuild
